{%- comment -%} Just the Docs builds one navigation list for the whole site, so every page would otherwise show both locales interleaved in the sidebar. There is no theme setting for a per-locale nav, so the other locale is hidden per page. Every French page is served under /fr/, and the French home page is exactly that prefix, so a single prefix test classifies every nav link. The prefix is resolved through relative_url so this keeps working under site.baseurl. Hiding rather than omitting is deliberate: the links stay in the document, so the built nav remains identical for both locales and a reader who lands on a French page with CSS disabled can still reach every page. The [href] guard matters. The theme drops the href from the link for the page being viewed, and without the guard the negated French rule would match that bare anchor and hide the current page from its own sidebar. {%- endcomment -%} {%- assign page_lang = page.lang | default: site.lang | default: 'en' -%} {%- assign fr_prefix = '/fr/' | relative_url -%}
